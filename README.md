# Café Loop React

Proyecto de cafetería convertido en una aplicación SPA con React y Vite.

## Tecnologías

- React y JSX
- React Router y Outlet
- Hooks useState y useEffect
- Bootstrap y Sass
- Fetch y json-server
- API REST simulada

## Instalación

```bash
npm install
```

## Ejecutar la aplicación

En una terminal:

```bash
npm run api
```

En otra terminal:

```bash
npm run dev
```

La API se ejecuta en `http://localhost:4000` y Vite muestra la dirección de la aplicación.
