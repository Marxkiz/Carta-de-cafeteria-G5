# Café Loop · versión final de ajustes visuales

Esta carpeta contiene los archivos de código de la versión final ajustada.

## Cambios principales
- Hero con el mensaje “Un café para encontrarse.”
- Header simplificado con una sola entrada “Cuenta”.
- Nueva presentación breve de identidad de marca.
- Segunda tarjeta editorial convertida en acceso al cuestionario.
- Eliminado el bloque gigante de “Café GOD”.
- Portada de tienda reducida a 3 productos.
- Sección Aprendé y Ubicación más compactas.
- Newsletter más breve.
- Eliminado el strip final naranja de filosofía.
- “Algo salado” pasa a “Opciones saladas” en el menú.
- Se conserva el carrito, cuenta, cuestionario e imágenes dinámicas.

## Importante
Conservá tu carpeta `images/` original y sus subcarpetas `menu/` y `tienda/` junto a estos archivos.

Estructura esperada:

```text
proyecto/
├── index.html
├── menu.html
├── tienda.html
├── style.css
├── script.js
├── imagenes.js
└── images/
    ├── menu/
    ├── tienda/
    └── ...
```

No reemplaces ni borres la carpeta `images/`.
